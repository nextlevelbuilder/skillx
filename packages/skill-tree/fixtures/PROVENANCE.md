## Unicode tables

`src/unicode-15-tables.ts` is generated by `scripts/gen-unicode-tables.mjs` from two pinned
inputs: the case folding file above, and `scripts/unicode-15.0.0-go.json`, which
`scripts/dump-go-unicode.go` writes from the Go `unicode` tables (go1.25.3) and
`golang.org/x/text/unicode/norm` (Unicode 15.0.0), the same tables the AgentKit reference
implementation validates paths with. To regenerate:

```sh
cd <agentkit>/apps/cli && go run <skillx>/packages/skill-tree/scripts/dump-go-unicode.go > <skillx>/packages/skill-tree/scripts/unicode-15.0.0-go.json
cd <skillx>/packages/skill-tree && node scripts/gen-unicode-tables.mjs
```

`scripts/unicode-15.0.0-go.json` is pinned at sha256
`baa335155dcbaf0cfe8f40fcc0a98232c4134e821a08c3f198f829a51d911ad5` (generator and tests).
Tests check the fold table against the case folding file, and the category and combining-class
tables against the Go dump, for every code point. They also check
normalization against the runtime's `String.prototype.normalize` for every code point assigned
in Unicode 15.0.0 (normalization stability makes later Unicode versions agree on those).
